# Chat Message ID Flow - Production Implementation Guide

**Last Updated:** October 12, 2025  
**Status:** ✅ Fully Implemented  
**Target Audience:** Frontend & Backend Developers

---

## 🎯 Executive Summary

This document defines the complete message ID flow for the chat system with **no temporary IDs**:
- Backend generates all IDs upfront (user_message_id, assistant_message_id, job_id)
- Frontend receives all IDs immediately in API response
- Frontend creates both messages with real IDs from the start
- SSE frames include `assistant_message_id` for direct message updates
- Worker creates assistant message with pre-generated ID

---

## 📋 The Approved Approach

### Core Principle
**Backend generates all IDs upfront and returns them immediately. Frontend uses real IDs from the start - no temporary IDs needed.**

### Why This Works
1. ✅ **No Temporary IDs**: Frontend uses real IDs immediately, no mapping needed
2. ✅ **Backend Control**: All persistent IDs generated by backend
3. ✅ **Instant UI Creation**: Frontend creates both user and assistant messages with real IDs right away
4. ✅ **Metadata Storage**: `session_id`, `user_message_id`, and `assistant_message_id` stored in job metadata for worker
5. ✅ **Simple SSE**: Every frame includes `job_id` and `assistant_message_id` for direct updates

### 2. Update `send_message` Handler

**File:** `src/api/routers/chat/messages_handler.py`

```python
@router.post("/send_message")
async def send_message(
    payload: SendMessageRequest = Body(...),
    service: ChatMessageService = Depends(get_chat_message_service),
    user_ids: UserIDs = Depends(get_current_user),
    _rl: None = Depends(rate_limit_user_write),
):
    try:
        # 1. Create user message
        user_message = await service.create_user_message(
            session_id=payload.session_id,
            content=payload.content,
            attachments=payload.attachments,
            message_type=payload.message_type,
            is_edited=payload.is_edited,
            edited_message_id=payload.edited_message_id,
        )
        
        # 2. Pre-create assistant message placeholder
        assistant_message = await service.create_assistant_message_placeholder(
            session_id=payload.session_id,
        )
        
        # 3. Create job with metadata
        job = await service.create_job(
            message_id=user_message.message_id,
            job_metadata={
                "session_id": str(payload.session_id),
                "user_message_id": str(user_message.message_id),
                "assistant_message_id": str(assistant_message.message_id),
            }
        )
        
        # 4. Enqueue Celery task
        chat_app.send_task(
            "chat.process_message",
            args=[str(user_ids.organisation_id), str(job.job_id)],
            queue="chat_queue"
        )
        
        # 5. Return response with all IDs
        return Response.success(
            SendMessageResponse(
                job_id=job.job_id,
                user_message_id=user_message.message_id,
                assistant_message_id=assistant_message.message_id,
            )
        )
        
    except ValueError as e:
        return Response.error(str(e), 400)
    except Exception as e:
        logger.error("Error sending message", exc_info=True)
        return Response.error("Failed to send message", 500)
```

### 3. Update Worker to Use Job Metadata

**File:** `src/workers/chat_worker/tasks/message_processing.py`

```python
@app.task(name="chat.process_message", bind=True)
def process_message_task(self, organisation_id: str, job_id: str) -> dict:
    """Process a chat message job."""
    
    org_uuid = UUID(organisation_id)
    job_uuid = UUID(job_id)
    
    session_gen, session = _get_sync_session(org_uuid)
    
    try:
        # Load job
        job = _load_job(session, job_uuid)
        
        # Extract from job_metadata (already stored!)
        metadata = job.job_metadata or {}
        session_id = UUID(metadata.get("session_id"))
        user_message_id = UUID(metadata.get("user_message_id"))
        assistant_message_id = UUID(metadata.get("assistant_message_id"))
        
        # Load user message
        user_message = session.get(ChatMessage, user_message_id)
        if not user_message:
            raise ValueError(f"User message {user_message_id} not found")
        
        # Load assistant message placeholder
        assistant_message = session.get(ChatMessage, assistant_message_id)
        if not assistant_message:
            raise ValueError(f"Assistant message {assistant_message_id} not found")
        
        # Initialize Redis publisher
        publisher = RedisPublisher(org_uuid, job_uuid)
        
        # Process message with agent
        result_summary = {
            "answer_parts": [],
            "final_answer": "",
            "confidence": None,
            "sources": [],
            "suggestions": [],
            "agent_name": None,
        }
        
        # Run agent (streaming to Redis)
        def streaming_callback(chunk: dict):
            """Callback for streaming chunks."""
            # Add job_id to every frame
            chunk["job_id"] = str(job_uuid)
            publisher.publish(chunk)
            _process_frame_data(chunk, result_summary)
        
        # Execute agent
        asyncio.run(
            run_agent_for_chat(
                session=session,
                user_message=user_message,
                session_id=session_id,
                organisation_id=org_uuid,
                streaming_callback=streaming_callback,
            )
        )
        
        # Update assistant message with final content
        final_content = result_summary.get("final_answer") or "".join(
            result_summary.get("answer_parts", [])
        )
        
        assistant_message.content = final_content
        assistant_message.confidence_score = result_summary.get("confidence")
        assistant_message.sources = result_summary.get("sources")
        assistant_message.suggestions = result_summary.get("suggestions")
        
        session.add(assistant_message)
        
        # Update job status
        job.status = JobStatus.COMPLETED
        job.result_data = result_summary
        session.add(job)
        
        session.commit()
        
        # Send finalize event
        publisher.publish({
            "type": FRAME_TYPE_FINALIZE,
            "job_id": str(job_uuid),
            "status": "completed",
        })
        
        logger.info(f"Completed job {job_uuid}")
        
        return {"status": "completed", "job_id": str(job_uuid)}
        
    except Exception as e:
        logger.error(f"Error processing job {job_uuid}", exc_info=True)
        
        # Update job as failed
        job.status = JobStatus.FAILED
        job.error_message = str(e)
        session.add(job)
        session.commit()
        
        # Send error event
        publisher = RedisPublisher(org_uuid, job_uuid)
        publisher.publish({
            "type": "error",
            "job_id": str(job_uuid),
            "message": "Processing failed",
        })
        
        raise
        
    finally:
        session.close()
        try:
            next(session_gen)
        except StopIteration:
            pass
```

        });

        if (!response.ok) {
          throw new Error('Failed to send message');
        }

        const result = await response.json();
        const data: SendMessageResponse = result.data;

        // Step 2: Add user message with real ID
        const userMessage: UserMessage = {
          message_id: data.user_message_id,
          session_id: sessionId,
          role: ChatMessageRole.USER,
          message_type: ChatMessageType.GENERAL_MESSAGE,
          content: content,
          status: MessageStatus.SENT,
          attachments: attachments?.map(id => ({ attachment_id: id, filename: '', mimetype: '' })) || [],
          is_edited: false,
          created_at: new Date().toISOString(),
          updated_at: new Date().toISOString(),
        };

        // Step 3: Add assistant placeholder with real ID
        const assistantPlaceholder: AssistantMessage = {
          message_id: data.assistant_message_id,
          session_id: sessionId,
          role: ChatMessageRole.ASSISTANT,
          message_type: ChatMessageType.GENERAL_MESSAGE,
          content: '',
          status: MessageStatus.STREAMING,
          suggestions: [],
          sources: [],
          created_at: new Date().toISOString(),
          updated_at: new Date().toISOString(),
        };

        // Add both messages to UI
        setMessages((prev) => [...prev, userMessage, assistantPlaceholder]);

        // Step 4: Connect to SSE
        connectToSSE(data.job_id);

        setIsSending(false);
      } catch (error) {
        console.error('Error sending message:', error);
        setIsSending(false);
        // Optionally show error toast
      }
    },
    [sessionId]
  );

  /**
   * Connect to SSE stream for a job
   */
  const connectToSSE = useCallback((jobId: string) => {
    const eventSource = new EventSource(
      `/api/chat/message_events?job_id=${jobId}`
    );

    activeConnections.current[jobId] = eventSource;

    eventSource.addEventListener('ready', (event) => {
      console.log('SSE ready:', event.data);
    });

    eventSource.addEventListener('frame', (event) => {
      const frame: SSEFrame = JSON.parse(event.data);
      handleSSEFrame(frame);
    });

    eventSource.addEventListener('complete', (event) => {
      console.log('SSE complete:', event.data);
      eventSource.close();
      delete activeConnections.current[jobId];
    });

    eventSource.addEventListener('error', (event) => {
      console.error('SSE error:', event);
      // EventSource will auto-reconnect
    });
  }, []);

  /**
   * Handle individual SSE frames
   */
  const handleSSEFrame = useCallback((frame: SSEFrame) => {
    // Frame includes assistant_message_id - use it directly!
    const assistantMessageId = frame.assistant_message_id;

    // Update message based on frame type
    setMessages((prev) =>
      prev.map((msg) => {
        if (msg.message_id !== assistantMessageId) return msg;

        const assistantMsg = msg as AssistantMessage;

        switch (frame.type) {
          case FrameType.ANSWER_DELTA:
            // Append content
            return {
              ...assistantMsg,
              content: assistantMsg.content + (frame as AnswerDeltaFrame).content,
              status: MessageStatus.STREAMING,
            };

          case FrameType.ANSWER_REPLACE:
            // Replace content
            return {
              ...assistantMsg,
              content: (frame as AnswerReplaceFrame).content,
            };

          case FrameType.ANSWER_METRICS:
            // Update confidence and sources
            const metricsFrame = frame as AnswerMetricsFrame;
            return {
              ...assistantMsg,
              confidence_score: metricsFrame.confidence,
              sources: metricsFrame.citations || assistantMsg.sources,
            };

          case FrameType.SUGGESTIONS_REPLACE:
            // Replace suggestions
            return {
              ...assistantMsg,
              suggestions: (frame as SuggestionsReplaceFrame).items,
            };

          case FrameType.SOURCES_REPLACE:
            // Replace sources
            return {
              ...assistantMsg,
              sources: (frame as SourcesReplaceFrame).sources,
            };

          case FrameType.AGENT_SWITCH:
            // Update agent name
            return {
              ...assistantMsg,
              agent_name: (frame as AgentSwitchFrame).agent_name,
            };

          case FrameType.FINALIZE:
            // Mark as completed
            return {
              ...assistantMsg,
              status: MessageStatus.COMPLETED,
            };

          default:
            return assistantMsg;
        }
      })
    );
  }, []);

  /**
   * Load messages from backend
   */
  const loadMessages = useCallback(async () => {
    try {
      const response = await fetch(
        `/api/chat/messages/list?session_id=${sessionId}&limit=50`
      );

      if (!response.ok) {
        throw new Error('Failed to load messages');
      }

      const result = await response.json();
      setMessages(result.data.items);
    } catch (error) {
      console.error('Error loading messages:', error);
    }
  }, [sessionId]);

  return {
    messages,
    isSending,
    sendMessage,
    loadMessages,
  };
}

## ✅ Approach Validation

### Is This a Good Approach? **YES! ✅**

#### Strengths

1. **✅ Instant UI Feedback**
   - User sees message immediately with temp ID
   - No perceived delay

2. **✅ Backend Control**
   - All persistent IDs generated by database
   - Single source of truth

3. **✅ Job Metadata Strategy**
   - Storing `session_id`, `user_message_id`, `assistant_message_id` in `job_metadata` is **excellent**
   - Worker can access everything it needs from one job record
   - No additional database queries needed

4. **✅ Simple SSE Protocol**
   - Backend only sends `job_id` in events
   - Frontend maintains mapping
   - No need to send message IDs in every event (good for bandwidth)

5. **✅ Recovery Support**
   - Frontend can reconnect using `job_id`
   - All metadata stored in backend for recovery

6. **✅ Clean Separation**
   - Frontend handles UI state (temp IDs)
   - Backend handles persistence (real IDs)
   - Job metadata bridges the two

#### Design Decisions Explained

1. **✅ Include `assistant_message_id` in every SSE frame**
   - Allows frontend to directly update the correct message
   - No need for job_id → message_id mapping
   - Simplifies frontend state management

2. **✅ Generate assistant_message_id before creating the message**
   - Frontend gets the ID immediately in API response
   - Can create UI placeholder with real ID right away
   - Worker creates actual message with the pre-generated ID

3. **✅ No temporary IDs needed**
   - Frontend waits for API response (fast)
   - Creates both messages with real IDs
   - No ID replacement logic needed
