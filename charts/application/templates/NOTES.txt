CONFIGURATION NOTES:
- To enable or disable a worker pool, edit the 'enabled' flag in your values.yaml file under the 'workers' section.
  For example:
  # Example enabling a new worker (pattern matches *-worker):
  my-new-worker:
    enabled: true
    replicaCount: 1
    config:
      queueName: my_new_queue

- To set workload identity client IDs via pipeline, pass --set api.workloadIdentity.clientId=<id> and
  --set worker.workloadIdentity.clientId=<id> (or inject per worker if you split identities).

- You can configure the image, replica count, resources, and queue for each worker independently from the top-level values.yaml.
