# Close Plan Stage Duration Benchmarks

Use these defaults to estimate remaining timeline when historical averages are missing.

## Default benchmarks

- Discovery -> 7 days
- Qualification -> 10 days
- Evaluation -> 14 days
- Validation -> 21 days
- Negotiation -> 14 days

## Benchmark preference

- If historical velocity is available, prefer real averages over defaults.

## Compression risk

- If remaining time is less than `0.75x` benchmark, mark `High compression risk`.
