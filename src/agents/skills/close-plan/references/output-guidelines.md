# Close Plan Output Guidelines

Use this guide to keep close plans direct, structured, and practical.

## Formatting

- Use a milestone table for the close plan.
- Keep headings aligned to the Output Contract.
- Use bullets for blockers.

## Tone

- Direct
- Action-oriented
- No vague optimism
- Clearly state `Unknown` where applicable

## Diagrams

- Include timeline visuals only if they improve clarity.
- Avoid decorative visuals.
