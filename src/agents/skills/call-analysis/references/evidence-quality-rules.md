# Evidence Quality Rules

## Evidence admissibility

- Prefer transcript quotes: speaker-attributed, verbatim excerpts are the gold standard.
- Meeting summaries are supporting signals, not sole proof for dimension ratings.
- Attendee metadata provides context (role, influence) but not call performance evidence.

## Citation requirements

- Every dimension rating must cite at least one concrete evidence item:
  - Transcript quote with speaker attribution
  - Meeting summary excerpt with specific detail
  - Attendee/stakeholder metadata for context
- Use `>` blockquotes for transcript excerpts with speaker name.
- Include approximate timestamp or position context when available.

## Quote handling

- Quote verbatim — do not paraphrase and present as a quote.
- If a quote is long, excerpt the most relevant portion with `[...]` for omissions.
- Keep quoted evidence in source language; add translated interpretation when the user's language differs.

## Absence of evidence

- If the transcript is unavailable, rely on meeting summary and clearly note reduced confidence.
- If neither transcript nor summary exists, rate affected dimensions `N/A` and explain.
- Never fabricate quotes or invent speaker dialogue.

## Contradiction rules

- If transcript contradicts summary, prefer the transcript (direct source).
- If multiple speakers give conflicting signals, note both and assess net impact.
- Explicitly call out contradictions in Key Takeaways.
