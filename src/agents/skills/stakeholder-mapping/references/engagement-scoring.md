# Stakeholder Mapping Engagement Scoring

Use this guide to assess stakeholder engagement and detect momentum loss from decay.

## Engagement rules

- `Active`: participated in the last two interactions or shows recent response activity.
- `Passive`: attends or replies but contributes little.
- `Disengaged`: no participation in 14+ days, adjusted by stage when relevant.
- `Unknown`: insufficient activity data.

## Evidence sources

- Meetings attended
- Transcript speaking share or explicit participation
- Email responsiveness
- Channel message activity

## Decay principle

- `Active` -> `Passive` -> `Disengaged` is an early momentum-loss signal.
- Explicitly note engagement decay when it is observed.

## Caution

- If no activity data exists at all, use `Unknown` rather than `Disengaged`.
