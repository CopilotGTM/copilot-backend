# Pipeline Review Output Guidelines

Use this guide to keep pipeline reviews concise, executive-ready, and easy to scan.

## Formatting rules

- Use sections that match the Output Contract.
- Use tables for ranked deal lists and owner breakdowns.
- Use bullets for risk reasoning.
- Avoid excessive narrative.

## Tone

- Executive-ready
- Direct
- No speculative language
- Explicitly state `Unknown` when relevant

## Diagrams

- Include visuals only when they materially improve clarity.
- Stage distribution is an acceptable optional visual.
- Avoid decorative visuals.
