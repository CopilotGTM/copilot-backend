# Competitive Analysis Output Format

Use this file to keep competitive analyses consistent and easy to act on.

## Required section order

1. Competitive Context Summary
2. Structured Comparison Matrix
3. Deal-Specific Competitive Risk Signals
4. Recommended Positioning Angles
5. Unknowns and Missing Evidence

## Comparison matrix format

Use a table with these columns only:

- `Dimension`
- `Us`
- `Competitor`
- `Relative Position`
- `Evidence Source`

Allowed `Relative Position` values: `Stronger`, `Comparable`, `Weaker`, `Unknown`.
Allowed `Evidence Source` values: `KB`, `Transcript`, `Email`, `Notes`, `Channel`, `External`,
`Unknown`.

## Risk section rules

List each risk as a flat bullet with:

- description
- evidence source
- risk impact: `Low`, `Medium`, `High`, or `Unknown`

Include stakeholder quotes, objections, timing shifts, and procurement behavior only when evidence
exists.

## Language rules

- Use a neutral analytical tone.
- Reply in the user's language.
- Keep explanations concise but evidence-based.
- Mark `Unknown` explicitly instead of guessing.
- Label externally sourced facts as external.

## Visualization guidance

- Add a chart or quadrant only if it materially improves clarity.
- If used, base it on the structured dimension scoring.
- Do not add decorative diagrams.
